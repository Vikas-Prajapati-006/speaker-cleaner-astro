# ClearWave Speaker Cleaner 🌊

An ultra-fast, client-side Web Audio application engineered to eject trapped water droplets and fine dust particles from smartphone speakers using resonant kinetic sound frequencies.

## Features

- **Acoustic Tone Generation**: Real-time sound wave sweep powered by the native HTML5 Web Audio API.
- **Model-Specific Calibration**: Dedicated resonant frequency profiles for Apple, Samsung, Google, Xiaomi, and OnePlus devices.
- **Zero Telemetry**: Runs 100% client-side with zero data collection or tracking.
- **Edge Optimized**: Built with Astro and Tailwind CSS, pre-rendered statically for high-speed edge distribution on Cloudflare Pages.

## Tech Stack

- **Framework**: [Astro](https://astro.build/) (Static Site Generation)
- **Styling**: [Tailwind CSS](https://tailwindcss.com/)
- **Audio**: HTML5 Web Audio API (`AudioContext`, `OscillatorNode`, `GainNode`)
- **Hosting**: Cloudflare Pages
